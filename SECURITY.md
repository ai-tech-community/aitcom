# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in AIT Community, please report it responsibly.

**Do not open a public issue.** Instead, email us at **security@aitcommunity.org** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 5 business days
- **Resolution target**: Within 30 days for critical issues

## Supported Versions

| Version | Supported |
| --- | --- |
| Latest on `main` | Yes |
| Older releases | No |

## Scope

The following are in scope:

- The AIT Community web application
- API endpoints
- Authentication and authorization
- Data exposure or leakage

Out of scope:

- Third-party services (Neon, Resend, Vercel, etc.)
- Social engineering attacks
- Denial of service attacks

## Recognition

We appreciate responsible disclosure and will credit reporters in our changelog (unless you prefer to remain anonymous).
