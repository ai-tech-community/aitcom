# Sponsors Journey Design

**Date:** 2026-02-23
**Approach:** Marketing Page + CMS Pipeline (Approach A)

## Goals

- Attract new sponsors with a clear value proposition and tiered benefits
- Showcase active sponsors to the community
- Full application pipeline with status tracking in Payload CMS
- Job board as a sponsor benefit and community value-add

## Data Model (Payload CMS Collections)

### Sponsors

Active/approved sponsors displayed publicly.

| Field | Type | Notes |
|-------|------|-------|
| name | text | Company name |
| logo | Media (relationship) | Company logo |
| website | text (url) | Company website |
| tier | select: gold/silver/bronze | Sponsorship tier |
| tagline | text | Short blurb |
| featured | checkbox | Show on homepage |
| status | select: active/inactive | Public visibility |

### SponsorApplications

Application pipeline managed by AIT team.

| Field | Type | Notes |
|-------|------|-------|
| companyName | text | |
| website | text (url) | |
| contactName | text | |
| contactEmail | email | |
| tier | select: gold/silver/bronze | Desired tier |
| message | textarea | Why they want to sponsor |
| status | select: pending/in_review/approved/rejected | Pipeline status |
| notes | textarea | Internal admin notes |
| appliedAt | date | Auto-set on creation |

### Jobs

Sponsor job postings visible to the community.

| Field | Type | Notes |
|-------|------|-------|
| title | text | Job title |
| sponsor | relationship → Sponsors | Posting company |
| description | richText (Lexical) | Job description |
| location | text | City/region |
| type | select: remote/hybrid/onsite | Work arrangement |
| url | text (url) | External apply link |
| tags | array of text | Skills/technologies |
| status | select: active/expired | Visibility |
| postedAt | date | |
| expiresAt | date | Auto-expire logic |

## Tier Structure & Benefits

| Benefit | Bronze | Silver | Gold |
|---------|--------|--------|------|
| Logo on sponsors page | Yes | Yes | Yes |
| Logo on homepage | No | Yes | Yes (larger) |
| Job postings | 1 active | 3 active | Unlimited |
| Event presence | No | Yes | Yes + co-host |
| Newsletter mentions | Quarterly | Monthly | Monthly + social |

## Pages & Routes

### `/[locale]/sponsors` — Main Sponsor Page

- **Hero section:** "Power the AI community" — value proposition, community stats
- **Tier comparison:** Visual cards with benefits matrix per tier
- **Current sponsors showcase:** Logo grid (hidden/empty state when no sponsors yet)
- **CTA:** "Become a Sponsor" → opens application modal

### `/[locale]/jobs` — Public Job Board

- Filterable list of active job postings from sponsors
- Each card: title, company logo, location, type badge, apply button

### Application Modal (3 steps, on `/sponsors`)

1. Company info — name, website, contact name, email
2. Tier selection — visual cards with benefits summary
3. Message — why they want to sponsor AIT

## Application Pipeline

```
Applicant submits form → status: pending
  → AIT team reviews in Payload admin → status: in_review
    → Approved → auto-creates Sponsors entry, status: approved
    → Rejected → status: rejected
```

## Email Notifications (Resend)

1. **To applicant on submit:** Confirmation that application was received
2. **To AIT team on submit:** New application notification with link to admin
3. **To applicant on approval:** Welcome email confirming sponsorship

## Technical Implementation

### Payload CMS
- 3 new collections: `Sponsors`, `SponsorApplications`, `Jobs`
- Payload hook on `SponsorApplications` status change → auto-create `Sponsors` entry on approval + trigger emails

### tRPC
- `sponsors` router — public queries for active sponsors, submit application mutation
- `jobs` router — public queries for active jobs with filters

### Components
- `sponsor-tier-card.tsx` — tier comparison card
- `sponsor-logo-grid.tsx` — logo showcase grid
- `sponsor-application-modal.tsx` — 3-step form
- `job-card.tsx` — job listing card

### i18n
- New `sponsors` and `jobs` namespaces in `en.json` / `nl.json`

### Navigation
- Add "Sponsors" and "Jobs" links to navbar

### Database
- Drizzle migration auto-generated by Payload for the 3 new collections
