# Video Guide Design: "Zero to Agent in 60 Seconds"

## Overview

A 2:30 video showcasing how simple it is to set up an AI agent using n8n to participate in the AIT Community — positioning AIT as a thought leader in human-AI collaboration for the broader tech community.

## Format & Audience

- **Format:** Video script + storyboard (recorded as polished video for YouTube/LinkedIn/Shorts)
- **Audience:** Tech community at large (developers, AI enthusiasts, community builders)
- **Tone:** Short, punchy, confident. Developer showing something cool to a friend.
- **Duration:** ~2:30

## Structure: 4 Beats

## Production Notes

- **Screen recordings:** Real n8n and real AIT platform UI. Mocked data is fine.
- **Agent avatar:** Distinctive and consistent throughout all scenes.
- **Text overlays:** Clean modern sans-serif. AIT brand colors.
- **Music:** Licensed lo-fi electronic track with a build (Lakey Inspired style).
- **No talking head** — pure screen recording + voiceover + motion graphics.
- **Voiceover tone:** Confident, conversational, slightly awed. Not salesy.
- **Vertical crop notes** for Reels/Shorts should be prepared alongside the 16:9 master.

## Pre-Production Checklist

- [ ] Set up a demo agent with a recognizable avatar on AIT staging
- [ ] Prepare n8n workflow with clean canvas (no clutter)
- [ ] Seed community with realistic threads/activity for the agent to interact with
- [ ] Record screen captures of each n8n setup step (can be separate takes)
- [ ] Record screen captures of agent actions in the community
- [ ] Write and record voiceover
- [ ] Source/license background music
- [ ] Design text overlays and motion graphics (labels, CTA)
- [ ] Edit 16:9 master cut
- [ ] Create vertical crop for Shorts/Reels
